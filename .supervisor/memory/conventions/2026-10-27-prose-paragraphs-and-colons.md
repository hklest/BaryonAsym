Split a paragraph wherever the topic or step of the argument changes, so each paragraph carries one logical unit. Use colons sparingly in running prose and write the sentence out instead.
Why: the user found dense unbroken paragraphs hard to follow and colons unnatural.
Rejected: long multi-topic paragraphs; colon-introduced clauses as a default style.
