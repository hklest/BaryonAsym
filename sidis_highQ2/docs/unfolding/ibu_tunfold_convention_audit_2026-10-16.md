**CONVENTIONS IDENTICAL — no defect found.** An independent numpy rebuild of both chains' exact algebra reproduces the TUnfold tau=0 solution to **2.6e-15 (median)**, its fold to **1.6e-15**, and the release IBU k=4 to **1.7e-15**. ## 1. What each chain actually is (code-level)

IBU release chain [A1]: reads the S2′ variant response `M_ext` (R10-repointed, sha-gated) + the **central** migration ROOT for the raw data vector `h_data_bgsub_{ch}`(+`_w2`) and binmap [A1 lines 79–110, 270–317]; blocks via `derive_response_blocks` [A2 lines 516–563]: `f_i = F_i/(rm_i+F_i)` (0 where denominator empty), `d_sig = raw·(1−f_i)`, acceptance `A_j = gt_j/(gt_j+miss_j)`; IBU via `ibu_unfold` [A2 lines 623–726]: `A_ij = B_ij/P_j` (P = coherent prior = body+miss marginal for rapgap), `eps_j = Σ_i A_ij`, update `n_j ← (1/eps_j)Σ_i M_ji·d_sig_i`, start `n^(0)=P`, **k=4** selected [A1 line 105]; `dvar = raww2·(1−f_i)²` [A1 line 312]; output `cross_section_nb = yield/351000.0`.

TUnfold chain [A3]: builder [A3a] reads the **same** variant response files and the **same** central `h_data_bgsub_*`; identical keep/f_i/d_sig formulas (lines 232–242); writes `h_R_native` = TH2 with 490 reco × 245 truth physical bins, **misses in the reco/input-axis x-underflow** (line 263–265), errors sqrt(Bw2)/sqrt(missw2); writes `h_data_fakesub` = d_sig with errors sqrt(raww2·keep²). Driver [A3b]: `TUnfoldDensity(hR, kHistMapOutputVert, kRegModeNone, kEConstraintNone, kDensityModeNone)` + explicit curvature triplets; zero-error input bins patched to error 1.0 (lines 234–236 — numerically always 1.0, since zero-variance bins always have zero content); `SetInput(h_data_fakesub)`; tau grid **includes 0.0**; tau_sel = 1e-5 by the stated rule [A3b lines 75–81]; output `x/LUMI`.

**ROOT-internal normalization (the key semantic), from source** [A4, ROOT 6.38.04 `TUnfold.cxx`, constructor lines ~1699–1863]: for `kHistMapOutputVert`, TUnfold loops over truth columns, sums the response over the 490 physical reco rows **plus `GetBinContent(0,ix)` (the x-underflow miss row) plus overflow (0)** into `fSumOverY[j] = Σ_i B_ij + miss_j = coh_j`, and stores `fA_ij = B_ij / fSumOverY_j`. SetInput sees only the 490 physical bins; `Vyy = diag(input errors²)` [A4, `SetInput` lines ~2274–2330]; zero-variance bins would be excluded, but the driver patch removes that case.

**Target equivalence, derived:** the TUnfold model is `μ_i = Σ_j (B_ij/coh_j)·x_j` with x = the **full truth-fiducial marginal** (the miss enters only through the normalization). The IBU composite is: unfold with `A_ij = B_ij/coh_j` to the observed-fiducial `n^obs` then divide by `eps_j = gt_j/coh_j` — algebraically the identical model `μ = (B/coh)·x` with the identical x. The two chains estimate **the same object with the same response matrix**; they differ only in estimator (regularized WLS from data errors vs EM/Poisson-ML started at the prior and stopped at k=4).

## 4. Root-cause section

1. **Why the plots look troubling:** 43.7% of bins sit outside the IBU-stat ±1σ band largely because the two displayed per-bin uncertainties measure different things — `stat_tu` (linear WLS covariance incl. auto-propagated response MC-stat) is ×1.52/×1.56 the IBU toy sidecar median (v2.1 M4: no gate by design; v4 decomposition [A5]: the like-for-like **data-piece** ratio is **1.451/1.448** — TUnfold `EmatrixInput` data piece 5.7290%/6.3451% vs IBU 1000-toy sidecar 3.5902%/3.8330% of yield — and it **dominates**; the response-MC-stat piece, medians 1.4769%/1.5752%, only lifts 1.45→1.52/1.56; the stale v1 `STAT_RULE` string claiming EmatrixTotal is data-stat-only is superseded by the v4 N3 semantics) — **and** because the two estimators land on different points: TUnfold tau_sel ≈ tau0 ≈ WLS ≈ (Poisson ML modulo 0.2% weighting), while IBU k=4 sits a median 2.5–2.7% per bin away from its own ML fixed point, pulled toward the coherent prior by stopping at 4 iterations on data whose shape differs from the MC prior.
2. **Why k=4 looked unbiased in toys but is prior-pulled on data:** the v3 toy validation generates toys from the prior-consistent closure model, where IBU reaches its fixed point at k=1 and k=4 is trivially unbiased; on real data the EM map still iterates (dx=0.26/0.13 per step at k=4), so k=4 retains a prior-pull. The two statements are consistent; the toy result does not certify k=4 ≈ ML on data.
3. **The boundary bins:** 16/11 bins have ML on the positive-orthant boundary (x→0); WLS gives them negative values (14/11 bins at tau_sel, unclipped), the chain clips them (documented one-sided bias), and IBU decays toward 0 geometrically without ever crossing. Same physics, two intended mechanisms.
4. **The old ~0.992:** edge-dominated all-bin median of an unregularized solution vs a plain-prior k=4 reference (superseded basis); integrated agreement 1.0003–1.0004. No convention defect then or now.

## 5. Final verdict

**CONVENTIONS IDENTICAL** — all nine knobs verified; every numerical difference between the delivered TUnfold vector and the release IBU k=4 vector is attributed to intended method settings, quantified per bin:
- k=4 stopping / prior-pull: median 2.68%/2.47% (dominant; tracks the total bin-by-bin, med ratio 1.000, corr 0.89/0.86);
- WLS-vs-Poisson-ML weighting: 0.26%/0.21%;
- regularization (tau_sel vs tau0): 0.0015%/0.0013%;
- positivity clip: 14/11 bins, +0.028%/+0.011% integrated;
- stat-column definition difference: ×1.52/×1.56 median (not a convention defect; v2.1 M4).
No fix is required for convention reasons — the conventions are unaffected by anything found here. What this audit adds is **new, quantified estimator-level information**: the delivered k=4 nominal sits a median 2.68%/2.47% (healthy-support 2.06%/2.08%) per bin away from its own ML fixed point on data. The record's sensitivity evidence is local only (k-scan iters 1–10; reg_unc = k3/k5 half-difference, medians 0.5767%/0.5669%), and the dossier's fixed-point evidence is closure-only (v3 prior-consistent toys, fp at k=1). Whether the model+reg uncertainties cover the k=4 prior-pull on data is an **open P-METHOD-level question** to be routed to the dossier owner — not a convention defect.

In demonstrable terms, "100% identical" here means: identity to the float noise floor on **every input block** (data vector, f_i, response, prior, efficiency — deviations 0.0 to ≤4.9e-15) and on **both solvers' outputs at zero regularization** (numpy WLS ≡ ROOT TUnfold tau0: median 2.6e-15, max 1.4e-11 at cond 6.3e4; canonical IBU ≡ release: 1.7e-15) — ~11–12 significant digits of agreement on 245-bin vectors, on sha-gated inputs.
