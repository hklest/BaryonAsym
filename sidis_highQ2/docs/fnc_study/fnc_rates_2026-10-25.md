# First rate-level DATA vs scaled RAPGAP-π FNC comparison (high-Q² charged-hadron SIDIS FNC side study)

**Date:** 2026-10-25  
**Status:** first rate-level data vs RAPGAP-π 9134 comparison applying the verified normalization; uncorrected exploratory side study. No acceptance, efficiency, or radiative corrections; not Born level; no physics interpretation beyond the documented comparability limits.

## Mandatory comparability framing

RAPGAP-π 9134 is a **pure pion-exchange leading-neutron sample** (every event has a leading neutron). The scaled prediction `N_pred = 1.15059 × N_selected` is a prediction for the **π-exchange component of LN-tagged data only, not for inclusive data**; data LN-tagged yields contain π-exchange plus all other leading-neutron production mechanisms. An absolute inclusive-data rate comparison is **not meaningful**, and any π-exchange fraction must come from an external input, not from these ratios. MC FNC response is credible only inside reco `FncThetaN < 0.75 mrad`; out-of-cone MC rates are flagged **not credible**. The data proton-beam tilt is not modelled in MC, limiting absolute θ_n comparisons even in-cone. Every number below carries these caveats.

## Caveats

1. Pure π-exchange sample: absolute inclusive-data rate comparison is NOT meaningful; the scaled prediction is for the π-exchange component of LN-tagged data only; a π-exchange fraction is an external input, not an output of this study.
2. MC FNC response credible only in-cone (`FncThetaN<0.75 mrad`); out-of-cone MC rates are not credible.
3. Uncorrected: no acceptance, efficiency, radiative, or trigger corrections; not Born level.
4. Luminosity uncertainty 2.5% flat, correlated; separate from the Poisson statistics.
5. Proton-beam tilt not modelled in MC: absolute θ_n/φ_n comparisons limited even in-cone; φ_n coverage is detector geometry, not physics.
6. Only the reco tree `ChargedTot` is used; the merged 9134 file's doubled `ChargedTotGen` (uninitialized weights in the 4,502,688-row cycle) is never touched.
7. DJANGOH14/7091 appears only as unit-area shape context; no scale applied, no absolute rates quoted.
8. `N_pred = scale × N_selected` is valid only for like-for-like selections on the Stage-1/Stage-2-filtered study tree (not an unbiased Q²>3 sample).
9. Pre-selection populations differ between the event-level EVL tree (119,483) and `ChargedTot` (116,281); see the reconciliation above.
